## The licence

Every `@tour-kit/*` package is released under the [MIT licence](https://github.com/domidex01/tour-kit/blob/main/LICENSE):
core, react, hints, adoption, analytics, announcements, checklists, media,
scheduling, surveys, ai, vue and svelte.

- Use it in development **and in production**, commercially, on as many projects as you like.
- There is no licence key, no badge and no feature gate.
- Nothing in the library contacts a licence server.

You do not need to configure anything. Install the packages and ship.

## Removing the badge from older versions

Some older releases were published under commercial terms and render an
"Unlicensed" badge in production when no key is configured:

| Packages | Versions that show the badge |
|---|---|
| `@tour-kit/core`, `@tour-kit/react`, `@tour-kit/hints`, `@tour-kit/vue`, `@tour-kit/svelte` | 3.0.x (core, react, hints) and 1.0.x (vue, svelte), published under BSL 1.1 |
| `@tour-kit/adoption`, `analytics`, `announcements`, `checklists`, `media`, `scheduling`, `surveys`, `ai` | releases before October 2026 |

The MIT releases sit inside the same version ranges, so updating removes the badge
without editing `package.json`:

```bash
npm update
# or: pnpm update / yarn upgrade
```

Then, if your app still has licence wiring, delete it:

1. Remove `<LicenseProvider>` from your provider tree, and any `<LicenseGate>` or `<ProGate>` wrappers.
2. Uninstall `@tour-kit/license` and delete the `TOUR_KIT_LICENSE_KEY` / `NEXT_PUBLIC_TOUR_KIT_LICENSE_KEY` environment variables.
3. In Vue or Svelte, drop the `license` option from `provideTourKit()` / `<TourProvider>`. It is still accepted, but ignored.
4. `<ScheduleGate>` from `@tour-kit/scheduling` now renders its children unchanged. You can keep it or remove it.

<Callout type="info">
Already-published versions keep the licence they were released under. Updating is
what moves you to MIT. If you bought a key, it keeps working on the versions it
was bought for and nothing is revoked; receipts and invoices are on the
[past purchases](/account) page.
</Callout>

## `@tour-kit/license` is retired

The package that validated keys is deprecated on npm and nothing in Tour Kit
depends on it any more. Existing installs keep working; there will be no new
releases.
