`@tour-kit/scheduling` is mostly hooks and pure functions. It ships one component,
`ScheduleGate`, which is deprecated.

## ScheduleGate

<Callout type="warn">
**Deprecated.** `ScheduleGate` used to fence the scheduling package behind the
paid licence. Tour Kit is MIT now, so it renders its `children` unchanged. It is
kept so existing imports still compile; you can remove it.
</Callout>

`ScheduleGate` never evaluated a schedule. To show UI only while a schedule is
active, read `useSchedule` (or call `isScheduleActive`) and branch in your own
render:

```tsx
import { useSchedule } from '@tour-kit/scheduling'

function ScheduledTour() {
  const { isActive } = useSchedule({
    startAt: '2026-01-15',
    endAt: '2026-03-31',
    timeOfDay: { start: '09:00', end: '17:00' },
  })

  return isActive ? <Tour tourId="weekly" /> : null
}
```

### Props

| Prop | Type | Description |
|------|------|-------------|
| `children` | `ReactNode` | Rendered as-is |
